# Учебные тесты (Quiz)

Приложение на FastAPI для проведения тестов в классе:

- **Супер-админ** создаёт учётные записи **учителей**.
- **Учитель** на компьютере создаёт предметы и тесты с вопросами, запускает тест
  и получает код.
- **Ученики** на телефонах вводят только код и своё имя и отвечают на вопросы
  (без регистрации, без доступа к редактированию).
- Вопросы идут по одному; правильный ответ показывается автоматически, когда
  **все ответили или закончилось время** вопроса.
- В конце показывается **рейтинг участников** по набранным очкам.
- Всё работает в реальном времени через WebSocket.

## Стек

FastAPI · SQLAlchemy · SQLite · Jinja2 · WebSocket (без внешнего JS-фреймворка).

## Роли

| Роль | Что может |
| --- | --- |
| **superadmin** | создавать учителей, а также всё, что может учитель |
| **teacher** | создавать предметы, тесты, вопросы и проводить их |
| **student** | только ввести код и имя, отвечать на вопросы (без входа) |

При первом запуске создаётся супер-админ:

- логин: **admin**
- пароль: **admin123**

> После первого входа рекомендуется сменить пароль администратора (или задать
> свой в функции `ensure_superadmin` в `app/main.py` перед запуском).

## Установка и запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить
python run.py
```

Приложение будет доступно на `http://127.0.0.1:8000`.

> Сервер слушает `0.0.0.0`, поэтому ученики могут открыть приложение с телефонов,
> зайдя по адресу `http://<IP-компьютера-преподавателя>:8000` (компьютер и телефоны
> должны быть в одной Wi-Fi сети). Узнать IP можно командой `ipconfig` (Windows).

## Как пользоваться

1. Супер-админ входит под `admin` и на странице **«Учителя»** создаёт учётные
   записи преподавателей.
2. Учитель входит и на главной добавляет **предмет** (например, «Математика»).
3. В предмете создаёт **тест** и добавляет вопросы (текст, время на ответ,
   варианты, отметьте правильный).
4. Нажимает **«Запустить тест»** — на экране появляется 6-значный код.
5. Ученики на телефонах открывают приложение → **«Я ученик»** → вводят код и имя.
6. Учитель нажимает **«Начать викторину»**. Ответ на вопрос откроется сам, когда
   все ответят или выйдет время.
7. После последнего вопроса — **«Показать результаты»**: рейтинг по очкам.

## Правила начисления очков

За каждый правильный ответ — **100 очков**, за неправильный — 0. Рейтинг строится
по сумме очков. Можно легко добавить бонус за скорость ответа, изменив расчёт
очков в функции `handle_answer` в `app/main.py`.

## Возможные доработки

- Смена пароля пользователем.
- Редактирование вопросов (сейчас — удалить и создать заново).
- Бонус за скорость ответа.
- Типы вопросов с несколькими правильными ответами или свободным текстом.
