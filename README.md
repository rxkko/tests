# Учебные тесты (Quiz)

Простое приложение на FastAPI для проведения тестов в классе:

- **Преподаватель** на компьютере создаёт предметы и тесты с вопросами,
  запускает тест и получает код.
- **Ученики** на телефонах вводят код и своё имя, отвечают на вопросы.
- Вопросы идут по одному, преподаватель управляет темпом (открывает ответ и
  переходит к следующему).
- В конце показывается **рейтинг участников** по набранным очкам.
- Всё работает в реальном времени через WebSocket.

## Стек

FastAPI · SQLAlchemy · SQLite · Jinja2 · WebSocket (без внешнего JS-фреймворка).

## Установка и запуск

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить
python run.py
```

Приложение будет доступно на `http://127.0.0.1:8000`.

> Сервер слушает `0.0.0.0`, поэтому ученики могут открыть приложение с телефонов,
> зайдя по адресу `http://<IP-компьютера-преподавателя>:8000` (компьютер и телефоны
> должны быть в одной Wi-Fi сети). Узнать IP можно командой `ipconfig` (Windows).

## Как пользоваться

1. На главной странице добавьте **предмет** (например, «Математика»).
2. В предмете создайте **тест** и добавьте вопросы (текст, время, варианты ответа,
   отметьте правильный).
3. Нажмите **«Запустить тест»** — на экране преподавателя появится 6-значный код.
4. Ученики на телефонах открывают приложение, нажимают «Я ученик», вводят код и имя.
5. Преподаватель нажимает **«Начать викторину»** — ученикам показывается первый вопрос.
6. После ответов преподаватель нажимает **«Открыть правильный ответ»**, затем
   **«Следующий вопрос»**.
7. После последнего вопроса — **«Показать результаты»**: рейтинг по очкам.

```

├── app/
│   ├── main.py          # маршруты + WebSocket-логика викторины
│   ├── models.py        # модели БД (предмет, тест, вопрос, участник, ответ)
│   ├── database.py      # подключение к SQLite
│   ├── ws.py            # менеджер WebSocket-соединений
│   ├── templates/       # HTML-страницы
│   └── static/style.css # стили
├── requirements.txt
├── run.py
└── quiz.db              # база данных (создаётся автоматически)
```

## Правила начисления очков

За каждый правильный ответ — **100 очков**, за неправильный — 0. Рейтинг строится
по сумме очков. Можно легко добавить бонус за скорость ответа, изменив расчёт
очков в функции `handle_answer` в `app/main.py`.

## Возможные доработки

- Редактирование вопросов (сейчас — удалить и создать заново).
- Бонус за скорость ответа.
- Типы вопросов с несколькими правильными ответами или свободным текстом.
- Авторизация преподавателя.
